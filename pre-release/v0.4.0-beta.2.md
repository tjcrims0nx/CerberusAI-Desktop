# Cerberus Desktop v0.4.0-beta.2

## What's New

* **Beta Updater Pill**: Added a dedicated in-app update pill button that automatically polls the GitHub releases to detect and prompt for beta channel updates.
* **Bug Fixes**: Resolved an issue causing missing HTML tags during the implementation of the new updater pill, ensuring stable rendering of the message composer.
* **API Streaming Resolved**: Fixed the underlying Kubernetes NGINX Ingress controller configuration so LLM streaming responses no longer timeout.
