# Cerberus Desktop v0.4.0-beta.1

## What's New

* **New Download UI**: Replaced the progress bar with an advanced, glowing loader showing dynamic download states (pulling, resumed, etc.).
* **API Endpoints Updated**: The client now correctly pulls metadata and tags from `api.cerberusai.dev` and points to the new streaming backend.
* **Streaming Stability**: Fixed internal gateway buffering issues that caused SSE streaming to drop on large completions.
